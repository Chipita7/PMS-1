# Hybrid Bayesian Network — Streamlit Demo

This small Streamlit app lets you load the production Bayesian network pickle (`production_bayesian_network.pkl`) and run inference for `LINEUP_QUALITY_SCORE_LEVEL` given categorical feature levels.

Files to include in the same folder:

- `production_bayesian_network.pkl` — the pickled pgmpy DiscreteBayesianNetwork used for inference.
- `production_feature_info.json` — feature list and descriptions (the app will read feature names from here by default).
- `app.py` — this Streamlit application.

Run locally (Windows PowerShell):

```powershell
# (optional) create and activate virtual environment
python -m venv .venv; .\.venv\Scripts\Activate.ps1

# install requirements (this repo already has requirements.txt)
pip install -r requirements.txt

# run the Streamlit app
python -m streamlit run app.py
```

Notes:
- If the model uses integer encodings (0/1/2), the app will attempt to detect that and convert `Low`/`Medium`/`High` to 0/1/2 automatically.
- If your production model or state mapping file uses different names, adjust `production_feature_info.json` or the model path in the sidebar.
